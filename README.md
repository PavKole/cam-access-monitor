# cam-access-monitor

Мини-система для наблюдения за камерой и учёта пропусков.

## Что делает

- Принимает RTSP-поток с IP-камеры (эмулятора).
- Сохраняет кадры каждые N секунд.
- Принимает события проходов по пропускам через REST API.
- Хранит события в PostgreSQL.
- Отдаёт простой веб-интерфейс: последний кадр + список событий.

## Стек

- Docker + Docker Compose
- Python + FastAPI + SQLAlchemy
- PostgreSQL
- ffmpeg (захват кадров)
- MediaMTX (эмулятор RTSP-камеры)
- Nginx (reverse proxy)
